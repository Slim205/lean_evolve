lemma odd_part_noninc_step
  (m n : ℕ → ℕ)
  (h_recurrence : ∀ k : ℕ,
    (m (k + 1) : ℚ) / (n (k + 1) : ℚ) = ((2 : ℚ) * (m k : ℚ) + 1) / ((2 : ℚ) * (n k : ℚ) + 1))

    Int.natAbs ((m k : ℤ) - (n k : ℤ)) = (2 : ℕ) ^ u1 * r1 →
    r1 % 2 = 1 → 0 < r1 →
    Int.natAbs ((m (k + 1) : ℤ) - (n (k + 1) : ℤ)) = (2 : ℕ) ^ u2 * r2 →
    r2 % 2 = 1 → 0 < r2 → r2 ≤ r1 := by
Failure mode: HARD
Recommendation: The statement is plausible but too “one-shot”; prove it via a gcd-normalization identity and a lemma about odd parts under division by an odd divisor.
1) Lemma (successor is normalized by gcd): For each `k`, with `d := gcd(2*m k + 1, 2*n k + 1)`, use the rational recurrence plus `Coprime (m (k+1)) (n (k+1))` (from `h_coprime` at `k+1`) to show  
   `m (k+1) = (2*m k + 1) / d` and `n (k+1) = (2*n k + 1) / d`.
2) Lemma (gcd is odd and divides the old difference): Show `d` is odd and `d ∣ (m k - n k)` (in `ℤ` or in `ℕ` for `natAbs`), using that `d ∣ (2*m k + 1)` and `d ∣ (2*n k + 1)`.
3) Lemma (difference recurrence): Deduce
   `m (k+1) - n (k+1) = (2*(m k - n k)) / d` (in `ℤ`, with appropriate coercions).
4) Lemma (effect on odd part): For `X > 0` and odd `d` with `d ∣ X`, if `X = 2^u * r` with `r` odd, then the odd part of `X / d` is `r / d` and in particular is `≤ r`.
