Failure mode: HARD

1) Lemma: For every positive natural `A`, the set `{u | 2^u ∣ A}` is nonempty.  
2) Lemma: For positive `A`, the set `{u | 2^u ∣ A}` is bounded above by `A` (or by `Nat.log 2 A + 1`), hence finite.

4) Lemma: If `u` is the maximum with `2^u ∣ A`, then `¬(2^(u+1) ∣ A)`.  
5) Conclude the desired existence by choosing `u = max {u | 2^u ∣ A}`.

lemma odd_part_noninc_step
  (m n : ℕ → ℕ)
  (h_recurrence : ∀ k : ℕ,
    (m (k + 1) : ℚ) / (n (k + 1) : ℚ) = ((2 : ℚ) * (m k : ℚ) + 1) / ((2 : ℚ) * (n k : ℚ) + 1))
  (h_coprime : ∀ k : ℕ, 0 < k → Nat.Coprime (m k) (n k)) :
  ∀ k u1 r1 u2 r2,
    Int.natAbs ((m k : ℤ) - (n k : ℤ)) = (2 : ℕ) ^ u1 * r1 →
    r1 % 2 = 1 → 0 < r1 →
    Int.natAbs ((m (k + 1) : ℤ) - (n (k + 1) : ℤ)) = (2 : ℕ) ^ u2 * r2 →
    r2 % 2 = 1 → 0 < r2 → r2 ≤ r1
Failure mode: HARD
Recommendation: As stated, this needs substantial number-theoretic infrastructure connecting the recurrence to a gcd-normalized update rule, and then relating that rule to the odd-part (2-adic) decomposition. A workable plan is:
1) Lemma (nonzero denominators): From `h_recurrence`, prove `(n (k+1) : ℚ) ≠ 0` and `((2:ℚ)*(n k:ℚ)+1) ≠ 0`.  
2) Lemma (reduced successor pair): Let `d = gcd (2*m k + 1) (2*n k + 1)`. Using `h_recurrence` and `Nat.Coprime (m (k+1)) (n (k+1))` (from `h_coprime` at `k+1`), prove
   `m (k+1) = (2*m k + 1)/d` and `n (k+1) = (2*n k + 1)/d`.  
3) Lemma (difference formula): With the same `d`, prove in ℤ:
   `(m (k+1) : ℤ) - (n (k+1) : ℤ) = (2*((m k : ℤ) - (n k : ℤ)))/d`.  
4) Lemma (d is odd and divides the difference): Prove `d` is odd and `(d : ℤ) ∣ ((m k : ℤ) - (n k : ℤ))`.  
5) Lemma (odd-part behavior under scaling): If `d` is odd and divides `Δ`, then the odd part of `|2*Δ/d|` is ≤ the odd part of `|Δ|`. (Here “odd part” is the unique odd `r` in `|Δ| = 2^u*r`.)  
6) Lemma (uniqueness of odd part): If `A = 2^u*r` with `r` odd and positive, then `r` equals `oddPart(A)`; use this to replace the quantification over `u1 r1 u2 r2` by a statement about a canonical odd-part function.  
7) Combine (3–6) to conclude `r2 ≤ r1`.

lemma odd_part_strict_decrease_of_not_coprime'
  (m n : ℕ → ℕ)
  (hΔ : ∀ k : ℕ, (m k : ℤ) - (n k : ℤ) ≠ 0)
  (h_coprime : ∀ k : ℕ, 0 < k → Nat.Coprime (m k) (n k))
  (h_recurrence : ∀ k : ℕ,
    (m (k + 1) : ℚ) / (n (k + 1) : ℚ) = ((2 : ℚ) * (m k : ℚ) + 1) / ((2 : ℚ) * (n k : ℚ) + 1))
  (k : ℕ)
  (hbad : ¬Nat.Coprime (2 * m k + 1) (2 * n k + 1)) :
  ∀ u1 r1 u2 r2,
    Int.natAbs ((m k : ℤ) - (n k : ℤ)) = (2 : ℕ) ^ u1 * r1 →
    r1 % 2 = 1 → 0 < r1 →
    Int.natAbs ((m (k + 1) : ℤ) - (n (k + 1) : ℤ)) = (2 : ℕ) ^ u2 * r2 →
    r2 % 2 = 1 → 0 < r2 → r2 < r1
Failure mode: HARD
Recommendation: This is the “strict” version of the previous lemma, and it needs one extra ingredient: the gcd `d` is > 1, hence it strictly shrinks the odd part. A proof plan:
1) Lemma: From `hbad`, with `d = gcd (2*m k + 1) (2*n k + 1)`, prove `1 < d`.  
2) Lemma: Derive the normalized update rule `m(k+1) = (2*m k + 1)/d`, `n(k+1) = (2*n k + 1)/d` (same as in the nonincreasing plan).  
3) Lemma: Prove the difference relation `(m (k+1) : ℤ) - (n (k+1) : ℤ) = 2*((m k : ℤ) - (n k : ℤ))/d`.  
4) Lemma: Prove `d` is odd and divides `((m k : ℤ) - (n k : ℤ))`.  
5) Lemma (odd-part strictly drops when dividing by a nontrivial odd factor): If `Δ ≠ 0`, `d` is odd, `1 < d`, and `d ∣ Δ`, then the odd part of `|2*Δ/d|` is strictly less than the odd part of `|Δ|`.  
6) Lemma (positivity/compatibility): Use `hΔ` to ensure the odd parts are positive and to rule out degenerate cases where strictness could fail.  
7) Use uniqueness of odd-part decomposition to translate the strict inequality into `r2 < r1` for the quantified decompositions.
