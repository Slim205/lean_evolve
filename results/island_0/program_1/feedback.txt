lemma diff_ne_zero
  (m n : ℕ → ℕ)
  (h_distinct : m 0 ≠ n 0)
  (h_recurrence : ∀ k : ℕ,
    (m (k + 1) : ℚ) / (n (k + 1) : ℚ) = (2 * (m k : ℚ) + 1) / (2 * (n k : ℚ) + 1)) :
  ∀ k : ℕ, (m k : ℤ) - (n k : ℤ) ≠ 0 := by
Failure mode: HARD
Recommendation: Prove it by “equality propagates backwards”, then induct.
1) Lemma: For all k, \((2*(m k:ℚ)+1) / (2*(n k:ℚ)+1) \neq 0\).
2) Lemma: For all k, from the recurrence conclude \((m (k+1):ℚ)/(n (k+1):ℚ) \neq 0\), hence \(n(k+1) \neq 0\) in ℕ.
3) Lemma: For all k, if \(m(k+1)=n(k+1)\) then \((m (k+1):ℚ)/(n (k+1):ℚ)=1\) (using \(n(k+1)\neq 0\)).
4) Lemma: For all k, if \((2*(m k:ℚ)+1)/(2*(n k:ℚ)+1)=1\) then \(m k = n k\) (clear denominators since \(2*n k+1 \neq 0\)).
5) Lemma (backward step): For all k, \(m(k+1)=n(k+1) \rightarrow m k = n k\) (combine 3, recurrence, 4).
6) Induction: prove \(m k \neq n k\) for all k by contraposition using the backward step and the base case \(m0\neq n0\); convert \(m k \neq n k\) to \((m k:ℤ)-(n k:ℤ)\neq 0\).

lemma finite_of_strict_decrease_on_bad
  (t : ℕ → ℕ)
  (htpos : ∀ k : ℕ, 0 < t k)
  (bad : ℕ → Prop)
  (hnoninc : ∀ k : ℕ, t (k + 1) ≤ t k)
  (hdec : ∀ k : ℕ, bad k → t (k + 1) < t k) :
  {k : ℕ | bad k}.Finite := by
Failure mode: HARD
Recommendation: Reduce finiteness to a numerical bound on how many strict drops can occur starting from \(t 0\).
1) Lemma: For any k, if \(bad k\) then \(t(k+1) + 1 \le t k\) (strict decrease in ℕ gives a drop of at least 1).
2) Lemma: For any k, along any interval \([0,k]\), the number of indices i with \(bad i\) is ≤ \(t 0 - t (k+1)\) (sum the “drops ≥ 1” over bad indices and use nonincreasing on non-bad steps).
3) Lemma: Using positivity, \(t (k+1) \ge 1\), hence the number of bad indices in \([0,k]\) is ≤ \(t 0 - 1\).
4) Lemma: If every initial segment \([0,k]\) contains at most \(N\) bad indices (same N for all k), then the full set \(\{k \mid bad k\}\) is finite.
5) Conclude with \(N := t 0 - 1\).

lemma exists_odd_measure
  (m n : ℕ → ℕ)
  (hΔ : ∀ k : ℕ, (m k : ℤ) - (n k : ℤ) ≠ 0)
  (h_recurrence : ∀ k : ℕ,
    (m (k + 1) : ℚ) / (n (k + 1) : ℚ) = (2 * (m k : ℚ) + 1) / (2 * (n k : ℚ) + 1)) :
  ∃ (t : ℕ → ℕ),
    (∀ k : ℕ, 0 < t k) ∧
    (∀ k : ℕ, t (k + 1) ≤ t k) ∧
    (∀ k : ℕ, (¬Nat.Coprime (2 * m k + 1) (2 * n k + 1)) → t (k + 1) < t k) := by
Failure mode: INCORRECT
Recommendation: As stated, the premises are too weak: the recurrence only constrains the *ratio* in ℚ, so you can rescale \((m(k+1), n(k+1))\) by arbitrary large factors without breaking the recurrence. That freedom can make any “difference-derived” measure (or any measure forced to strictly drop on some bad steps) fail to be globally nonincreasing or fail to strictly decrease when “bad” happens. To fix this, strengthen the hypotheses so that \((m(k+1), n(k+1))\) is the reduced form of \((2m k+1, 2n k+1)\), e.g. assume a normalization lemma like:
- \(m(k+1) = (2 m k + 1)/d\) and \(n(k+1) = (2 n k + 1)/d\) where \(d = \gcd(2 m k + 1, 2 n k + 1)\),
and/or assume \(Nat.Coprime (m (k+1)) (n (k+1))\).
Then you can *define* \(t(k)\) explicitly (e.g. via the odd part of \(|m k - n k|\)) and prove the three required properties, rather than postulating an abstract existence from just the ratio recurrence.
