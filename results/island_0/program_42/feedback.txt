  (hd_odd : d % 2 = 1) (hdiv : (d : ℤ) ∣ z) :
  Int.natAbs (((2 : ℤ) * z) / (d : ℤ)) = 2 * (Int.natAbs z / d) := by

Recommendation: Rewrite using an exact quotient `w` with `z = d*w`, then separate the “abs” and “exact Nat division” parts.
1) Lemma: From `hdiv`, obtain `w : ℤ` with `z = (d : ℤ) * w`.
2) Lemma: `d % 2 = 1 → (d : ℤ) ≠ 0` and `(0 : ℤ) < (d : ℤ)`.
3) Lemma (exact ℤ-division): with `d ≠ 0`, `((2 : ℤ) * ((d : ℤ) * w)) / (d : ℤ) = (2 : ℤ) * w`.
4) Lemma: `Int.natAbs ((2 : ℤ) * w) = 2 * Int.natAbs w`.
5) Lemma: `Int.natAbs z = d * Int.natAbs w` (uses positivity of `(d:ℤ)` and multiplicativity of `natAbs` on ℤ-products with a nonnegative factor).
6) Lemma (exact ℕ-division): from (5), `Int.natAbs z / d = Int.natAbs w`.
7) Combine (3)–(6) to get the desired equality.

7) Conclude `r2 = q ≤ r1` (since `q = r1 / d` and `d ≥ 1`).
