lemma finite_of_card_bounded {P : ℕ → Prop} (N : ℕ) [DecidablePred P]
  (hcard : ∀ K, (Finset.filter (fun i => i < K ∧ P i) (Finset.range K)).card ≤ N) :
  {k : ℕ | P k}.Finite := by
Failure mode: HARD
Recommendation: Prove finiteness by turning “uniform bounded prefix-cardinality” into “cannot pick N+1 distinct witnesses”.
1) Lemma (prefix-captures-finite-set): For any finite set `F : Finset ℕ`, if `∀ x ∈ F, P x`, then with `K := (F.max' ?) + 1` one has `F ⊆ (Finset.filter (fun i => i < K ∧ P i) (Finset.range K))`.
2) Lemma (card_le_from_prefix_bound): Under `hcard`, any finite set `F` of pairwise distinct `P`-witnesses has `F.card ≤ N` (combine (1) with monotonicity of `card` under inclusion).
3) Lemma (infinite_gives_large_finite_subset): If `{k | P k}` is infinite, then for any `M` there exists a finite subset `F ⊆ {k | P k}` with `F.card = M`.
4) Conclude by contradiction with `M := N+1`: (2) says `F.card ≤ N` but (3) gives `F.card = N+1`.

lemma odd_part_noninc_step
  (m n : ℕ → ℕ)
  (h_recurrence : ∀ k : ℕ,
    (m (k + 1) : ℚ) / (n (k + 1) : ℚ) = ((2 : ℚ) * (m k : ℚ) + 1) / ((2 : ℚ) * (n k : ℚ) + 1))
  (h_coprime : ∀ k : ℕ, 0 < k → Nat.Coprime (m k) (n k)) :
  ∀ k u1 r1 u2 r2,
    Int.natAbs ((m k : ℤ) - (n k : ℤ)) = (2 : ℕ) ^ u1 * r1 →
    r1 % 2 = 1 → 0 < r1 →
    Int.natAbs ((m (k + 1) : ℤ) - (n (k + 1) : ℤ)) = (2 : ℕ) ^ u2 * r2 →
    r2 % 2 = 1 → 0 < r2 → r2 ≤ r1 := by
Failure mode: HARD
Recommendation: The statement is plausible but requires substantial arithmetic normalization of the recurrence; decompose it into “successor equals reduced fraction” + “odd part monotone under dividing by an odd gcd”.
1) Lemma (succ_is_reduced_div_gcd): Let `A := 2*m k + 1`, `B := 2*n k + 1`, `d := gcd A B`. Using `h_recurrence k` and coprimality of `(m (k+1), n (k+1))` (from `h_coprime (k+1)`), prove `m (k+1) = A / d` and `n (k+1) = B / d`.
2) Lemma (gcd_odd_dvd_diff): With the same `d`, prove `d` is odd and `d ∣ (m k - n k)` (in ℤ or ℕ), using that `d ∣ (A - B) = 2*(m k - n k)` and `d` odd.
3) Lemma (diff_succ_formula): From (1) derive an exact relation
   \[
   (m (k+1) : ℤ) - (n (k+1) : ℤ) = 2 * ((m k : ℤ) - (n k : ℤ)) / d
   \]
   in a form compatible with `Int.natAbs`.
4) Lemma (odd_part_monotone_under_div_odd): For `X : ℤ` and odd `d : ℕ` with `d ∣ X` (in the appropriate sense), show the odd factor in a `2^u * r` decomposition of `natAbs (2*X/d)` is ≤ the odd factor in a `2^u * r` decomposition of `natAbs X`.
5) Conclude `r2 ≤ r1` by applying (4) to the decompositions supplied in the hypotheses, using uniqueness of the “odd part” when `r` is constrained to be odd.

lemma odd_part_strict_decrease_of_not_coprime'
  (m n : ℕ → ℕ)
  (hΔ : ∀ k : ℕ, (m k : ℤ) - (n k : ℤ) ≠ 0)
  (h_coprime : ∀ k : ℕ, 0 < k → Nat.Coprime (m k) (n k))
  (h_recurrence : ∀ k : ℕ,
    (m (k + 1) : ℚ) / (n (k + 1) : ℚ) = ((2 : ℚ) * (m k : ℚ) + 1) / ((2 : ℚ) * (n k : ℚ) + 1))
  (k : ℕ)
  (hbad : ¬Nat.Coprime (2 * m k + 1) (2 * n k + 1)) :
  ∀ u1 r1 u2 r2,
    Int.natAbs ((m k : ℤ) - (n k : ℤ)) = (2 : ℕ) ^ u1 * r1 →
    r1 % 2 = 1 → 0 < r1 →
    Int.natAbs ((m (k + 1) : ℤ) - (n (k + 1) : ℤ)) = (2 : ℕ) ^ u2 * r2 →
    r2 % 2 = 1 → 0 < r2 → r2 < r1 := by
Failure mode: HARD
Recommendation: Strengthen the previous “nonincreasing” plan by using `hbad` to force division by a nontrivial odd factor, then show strict reduction of the odd part.
1) Lemma (not_coprime_iff_gcd_gt_one): From `hbad`, show that `d := gcd (2*m k + 1) (2*n k + 1)` satisfies `1 < d`.
2) Lemma (succ_is_reduced_div_gcd): As in the previous plan, deduce `m (k+1) = (2*m k + 1)/d` and `n (k+1) = (2*n k + 1)/d`.
3) Lemma (d_odd_and_dvd_diff): Show `d` is odd and `d ∣ (m k - n k)` (compatible with the integer difference), using oddness of a gcd of odd numbers.
4) Lemma (odd_part_strict_drop_under_divisor): If `r1` is odd and positive and `d` is an odd natural with `1 < d` and `d ∣ r1`, then `r1 / d < r1`.
5) Lemma (odd_part_tracks_division): Using the decompositions and the exact formula for the successor difference from (2)+(3), show that the odd part `r2` at time `k+1` is `r1 / d` (or at least ≤ `r1 / d`), and hence by (4) obtain `r2 < r1`.
