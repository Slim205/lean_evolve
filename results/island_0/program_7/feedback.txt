<lemma odd_part_noninc_step
  (m n : ℕ → ℕ)
  (h_recurrence : ∀ k : ℕ,
    (m (k + 1) : ℚ) / (n (k + 1) : ℚ) = ((2 : ℚ) * (m k : ℚ) + 1) / ((2 : ℚ) * (n k : ℚ) + 1))
  (h_coprime : ∀ k : ℕ, 0 < k → Nat.Coprime (m k) (n k)) :
  ∀ k u1 r1 u2 r2,
    Int.natAbs ((m k : ℤ) - (n k : ℤ)) = (2 : ℕ) ^ u1 * r1 →
    r1 % 2 = 1 → 0 < r1 →
    Int.natAbs ((m (k + 1) : ℤ) - (n (k + 1) : ℤ)) = (2 : ℕ) ^ u2 * r2 →
    r2 % 2 = 1 → 0 < r2 → r2 ≤ r1 := by>
Failure mode: HARD
Recommendation: This needs a substantial arithmetic bridge: relate `m (k+1), n (k+1)` to `(2*m k+1, 2*n k+1)` via gcd-reduction, then relate the odd parts of differences using divisibility by the gcd. Suggested lemma plan:
1) **Successor is gcd-reduction**: using `h_recurrence` and coprimality of `(m (k+1), n (k+1))` (from `h_coprime (k+1)`), prove
   - `let d := gcd(2*m k+1, 2*n k+1)`; then `m (k+1) = (2*m k+1)/d` and `n (k+1) = (2*n k+1)/d`.
2) **Gcd is odd**: prove `d % 2 = 1` since it is a gcd of two odd numbers.
3) **Gcd divides the previous difference**: prove `(d : ℤ) ∣ ((m k : ℤ) - (n k : ℤ))` via `d ∣ (2*m k+1) - (2*n k+1) = 2*(m k - n k)` and oddness of `d`.
4) **Difference recurrence in ℤ**: deduce
   \[
   (m(k+1)-n(k+1)) = \frac{2\,(m k - n k)}{d}
   \]
   as an equality in `ℤ` (well-defined since `d` divides the numerator).
5) **Push to natAbs**: rewrite `Int.natAbs` of the successor difference in terms of `Int.natAbs` of the previous difference, using (4).
6) **Odd-part effect**: from the decomposition `|Δ_k| = 2^{u1} r1` with `r1` odd and (3) with `d` odd, prove `d ∣ r1`.
7) **Compute successor odd part**: show the odd part of `|Δ_{k+1}|` is `r1 / d`, hence `r2 = r1 / d` by uniqueness of the “`2^u * odd`” decomposition.
8) **Conclude** `r2 ≤ r1` from `r2 = r1/d`.

(If you want this lemma to be usable “as stated”, you’ll likely need to explicitly include lemma (1) (your `next_eq_div_gcd`) as a dependency, because it is the critical normalization step.)
