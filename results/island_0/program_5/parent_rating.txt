<lemma odd_part_noninc_step
  (m n : ℕ → ℕ)
  (h_recurrence : ∀ k : ℕ,
    (m (k + 1) : ℚ) / (n (k + 1) : ℚ) = ((2 : ℚ) * (m k : ℚ) + 1) / ((2 : ℚ) * (n k : ℚ) + 1))
  (h_coprime : ∀ k : ℕ, 0 < k → Nat.Coprime (m k) (n k)) :
  ∀ k u1 r1 u2 r2,
    Int.natAbs ((m k : ℤ) - (n k : ℤ)) = (2 : ℕ) ^ u1 * r1 →
    r1 % 2 = 1 → 0 < r1 →
    Int.natAbs ((m (k + 1) : ℤ) - (n (k + 1) : ℤ)) = (2 : ℕ) ^ u2 * r2 →
    r2 % 2 = 1 → 0 < r2 → r2 ≤ r1 := by>
Failure mode: HARD
Recommendation: Make the hidden “normalization by gcd” explicit, then relate differences across steps and use uniqueness of the odd-part.
1) Lemma: Let \(d = gcd(2*m k + 1, 2*n k + 1)\). Using the recurrence and coprimality of \((m(k+1),n(k+1))\), prove
   \(m(k+1) = (2*m k + 1)/d\) and \(n(k+1) = (2*n k + 1)/d\).
2) Lemma: The same \(d\) divides \((m k : ℤ) - (n k : ℤ)\). (Because \(d\) divides the difference of the odd numbers \(2*m k+1\) and \(2*n k+1\), hence divides \(2(mk-nk)\), and \(d\) is odd so it divides \(mk-nk\).)
3) Lemma: Derive the exact relation
   \[
   Int.natAbs((m(k+1):ℤ)-(n(k+1):ℤ)) = \frac{2 * Int.natAbs((m k:ℤ)-(n k:ℤ))}{d}.
   \]
4) Lemma: If \(Int.natAbs(Δ_k) = 2^{u1} * r1\) with \(r1\) odd and \(d\) odd divides \(Int.natAbs(Δ_k)\), then \(d\) divides \(r1\).
5) Lemma: With \(r1 = d * r'\), rewrite Lemma 3 as
   \(Int.natAbs(Δ_{k+1}) = 2^{u1+1} * r'\) with \(r'\) odd.
6) Lemma (uniqueness): If a positive natural \(A\) admits decompositions \(A = 2^{u}*r\) and \(A = 2^{u'}*r'\) with both \(r,r'\) odd, then \(r=r'\).
7) Apply Lemma 6 to identify the given \(r2\) with the constructed \(r'\), and conclude \(r2 = r1/d ≤ r1\).
