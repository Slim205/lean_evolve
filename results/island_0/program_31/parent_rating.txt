<lemma odd_part_noninc_step
  (m n : ℕ → ℕ)
  (h_recurrence : ∀ k : ℕ,
    (m (k + 1) : ℚ) / (n (k + 1) : ℚ) = ((2 : ℚ) * (m k : ℚ) + 1) / ((2 : ℚ) * (n k : ℚ) + 1))
  (h_coprime : ∀ k : ℕ, 0 < k → Nat.Coprime (m k) (n k)) :
  ∀ k u1 r1 u2 r2,
    Int.natAbs ((m k : ℤ) - (n k : ℤ)) = (2 : ℕ) ^ u1 * r1 →
    r1 % 2 = 1 → 0 < r1 →
    Int.natAbs ((m (k + 1) : ℤ) - (n (k + 1) : ℤ)) = (2 : ℕ) ^ u2 * r2 →
    r2 % 2 = 1 → 0 < r2 → r2 ≤ r1 := by>
Failure mode: HARD
Recommendation:
1) **(Reduced successor form)** Prove: for each `k`, letting `d = gcd(2*m k + 1, 2*n k + 1)`, one has  
   `m (k+1) = (2*m k + 1)/d` and `n (k+1) = (2*n k + 1)/d`.  
   (This uses the rational recurrence plus the hypothesis that `m (k+1), n (k+1)` are coprime to pin down the unique reduced fraction.)

2) **(Oddness of the gcd)** Prove: with the same `d`, `d` is odd (`d % 2 = 1`).

3) **(Difference evolution formula)** Using (1), prove in `ℤ` that  
   `(m (k+1) : ℤ) - (n (k+1) : ℤ) = (2*((m k : ℤ) - (n k : ℤ))) / d`  
   together with the divisibility fact `((d : ℤ) ∣ ((m k : ℤ) - (n k : ℤ)))` (or the corresponding statement on `Int.natAbs`).

4) **(NatAbs scaling)** Prove a clean statement: if `d` is odd and divides `z` in `ℤ`, then  
   `Int.natAbs (2*z / d) = 2 * (Int.natAbs z / d)` and in particular the “odd part” of `Int.natAbs (2*z/d)` is ≤ the odd part of `Int.natAbs z`.

5) **(Identify `r` with odd part)** Prove uniqueness: if `A = 2^u * r` with `r` odd and `r>0`, then `r` is exactly the odd part of `A`. Conclude from (4) that `r2 ≤ r1`.

This isolates the genuine arithmetic content (reduction by gcd + behavior of odd parts under multiplying by 2 and dividing by an odd factor) from the bookkeeping with the decompositions.

<lemma odd_part_strict_decrease_of_not_coprime'
  (m n : ℕ → ℕ)
  (hΔ : ∀ k : ℕ, (m k : ℤ) - (n k : ℤ) ≠ 0)
  (h_coprime : ∀ k : ℕ, 0 < k → Nat.Coprime (m k) (n k))
  (h_recurrence : ∀ k : ℕ,
    (m (k + 1) : ℚ) / (n (k + 1) : ℚ) = ((2 : ℚ) * (m k : ℚ) + 1) / ((2 : ℚ) * (n k : ℚ) + 1))
  (k : ℕ)
  (hbad : ¬Nat.Coprime (2 * m k + 1) (2 * n k + 1)) :
  ∀ u1 r1 u2 r2,
    Int.natAbs ((m k : ℤ) - (n k : ℤ)) = (2 : ℕ) ^ u1 * r1 →
    r1 % 2 = 1 → 0 < r1 →
    Int.natAbs ((m (k + 1) : ℤ) - (n (k + 1) : ℤ)) = (2 : ℕ) ^ u2 * r2 →
    r2 % 2 = 1 → 0 < r2 → r2 < r1 := by>
Failure mode: HARD
Recommendation:
1) **(Reduced successor form, again)** Prove the same normalization lemma as above: with `d = gcd(2*m k + 1, 2*n k + 1)`,  
   `m (k+1) = (2*m k + 1)/d` and `n (k+1) = (2*n k + 1)/d`.

2) **(Nontrivial gcd from non-coprime)** Prove: `hbad` implies `d > 1`.

3) **(Oddness + divisibility into the difference)** Prove: `d` is odd and `d` divides `((m k : ℤ) - (n k : ℤ))` (or divides `Int.natAbs ((m k : ℤ) - (n k : ℤ))` in `ℕ`).

4) **(Exact odd-part update)** Using the difference evolution formula  
   `diff_{k+1} = 2*diff_k / d` with `d` odd and `d ∣ diff_k`, prove that the odd part satisfies  
   `oddPart(diff_{k+1}) = oddPart(diff_k) / d`.

5) **(Strictness)** Combine (2) and (4): since `d > 1`, dividing the (positive) odd part by `d` gives a strict inequality, hence `r2 < r1` after identifying `r1,r2` with the odd parts via the uniqueness lemma “`A = 2^u*r` with `r` odd implies `r = oddPart(A)`”.

This decomposition makes clear that the strict decrease is not “from recurrence alone”, but from (i) the reduced-form update and (ii) the fact that a nontrivial odd gcd is actually removed at that step, forcing the odd part to drop.
