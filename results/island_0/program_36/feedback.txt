<lemma gcd_odd_and_dvd_diff
  (m n : ℕ → ℕ)

Failure mode: HARD
Recommendation: Split into (i) “gcd of odd numbers is odd” and (ii) “odd gcd dividing 2⋅(diff) implies divides diff”.
1) Lemma (odd_2mul_add1): `((2 * x + 1) % 2 = 1)` for all `x : ℕ` (so both arguments to `gcd` are odd).
2) Lemma (gcd_odd_of_odd_left_right): If `a % 2 = 1` and `b % 2 = 1`, then `Nat.gcd a b % 2 = 1`.
3) Lemma (gcd_dvd_sub): Let `d = Nat.gcd a b`. Then `(d : ℤ) ∣ ((a : ℤ) - (b : ℤ))`.

5) Lemma (odd_dvd_of_dvd_two_mul): If `d % 2 = 1` and `(d : ℤ) ∣ (2*z)`, then `(d : ℤ) ∣ z`.

   (Key idea: `gcd(d,2^u1)=1` because `d` is odd; hence `d ∣ r1`.)
3) Lemma (A_div_d_factor): Using (2), rewrite `A / d = 2^u1 * (r1 / d)` with exact division.

<lemma odd_part_strict_decrease_of_not_coprime'
