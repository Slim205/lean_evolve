lemma gcd_odd_and_dvd_diff
  (m n : ℕ → ℕ)
  (k : ℕ) :
  let d : ℕ := Nat.gcd (2 * m k + 1) (2 * n k + 1)
  d % 2 = 1 ∧ ((d : ℤ) ∣ ((m k : ℤ) - (n k : ℤ))) := by
Failure mode: HARD
Recommendation:
1) Lemma: `2 * x + 1` is odd for all `x : ℕ`.
2) Lemma: if `a` and `b` are odd naturals, then `Nat.gcd a b` is odd (equivalently `% 2 = 1`).
3) Lemma: `Nat.gcd a b ∣ (a - b)` in `ℕ`, and correspondingly in `ℤ` after casting.
4) Apply (3) to `a = 2*m k + 1`, `b = 2*n k + 1` to get `(d : ℤ) ∣ ((2*m k + 1 : ℤ) - (2*n k + 1 : ℤ))`, i.e. `(d : ℤ) ∣ (2 * ((m k : ℤ) - (n k : ℤ)))`.
5) Lemma (odd-cancellation): if `d` is odd and `(d : ℤ) ∣ 2*z`, then `(d : ℤ) ∣ z`.
6) Combine (2), (4), (5) to conclude `(d : ℤ) ∣ ((m k : ℤ) - (n k : ℤ))`.
