lemma pow_mul_odd_eq_pow_mul_odd (p q x y : ℕ)
  (h : (2 : ℕ) ^ p * x = (2 : ℕ) ^ q * y) (hx_odd : x % 2 = 1) (hy_odd : y % 2 = 1) :
  p = q ∧ x = y := by
Failure mode: HARD
Recommendation: Decompose the goal via a 2-adic/“odd part” uniqueness argument. A workable lemma-plan is:

1) **Odd means not divisible by 2**: from `x % 2 = 1` derive `¬ (2 ∣ x)` and similarly for `y`.
2) **Compare exponents by divisibility**: prove `p ≤ q ∨ q ≤ p` and handle both cases symmetrically.
3) **If p ≤ q, factor out 2^p**: set `r := q - p` and rewrite the equality as  
   `x = (2^r) * y` (using cancellation of the common factor `2^p`).
4) **Odd forces r = 0**: show that if `r > 0` then `2 ∣ (2^r * y)`, hence `2 ∣ x`, contradicting oddness of `x`. Conclude `r = 0`, hence `p = q`.
5) **With p = q, cancel to get x = y**: substitute `p = q` back into `h` and cancel the common factor `2^p` to conclude `x = y`.

This avoids any heavy machinery: the key intermediate facts are “`r>0` implies `2 ∣ 2^r`” and “odd ↔ not divisible by 2”.
