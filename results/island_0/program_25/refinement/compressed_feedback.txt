  (hcop : Nat.Coprime a b)
  (hd : d ≠ 0)
  (h : (a : ℚ) / (b : ℚ) = (c : ℚ) / (d : ℚ)) :
  a = c / Nat.gcd c d ∧ b = d / Nat.gcd c d := by>
Failure mode: INCORRECT
Recommendation: The statement is false without assuming `b ≠ 0`. In `ℚ`, division by `0` is defined (as `x / 0 = 0`), so the equality of fractions does not force a reduced-form uniqueness conclusion. Counterexample: `a = 1, b = 0` (still coprime), `c = 0, d = 1` gives `1/0 = 0/1`, but the conclusion forces `1 = 0`. Revise the lemma by adding `hb : b ≠ 0` (and typically also rewrite the equality as a cross-multiplication statement), then prove uniqueness of reduced forms under `Nat.Coprime a b` and `b ≠ 0`.
