  (A d u1 r1 u2 r2 r1' : ℕ)
  (hA : A = (2 : ℕ) ^ u1 * r1)

Failure mode: HARD
Recommendation: Reduce to uniqueness of the 2-adic decomposition of `B := 2*(A/d)`.
1) Lemma: From `hd_odd : d % 2 = 1`, deduce `1 ≤ d` (in particular `d ≠ 0`).

   `A = d * (2^u1 * r1')`.
3) Lemma: Using (1) and the equality from (2), prove exact division:
   `A / d = 2^u1 * r1'`.
4) Lemma: Substitute into `B := 2*(A/d)` to get the canonical form
   `2 * (A / d) = 2^(u1+1) * r1'`.
5) Lemma: From `hr1_odd : r1 % 2 = 1`, `hd_odd : d % 2 = 1`, and `hr1_eq : r1 = d * r1'`, deduce `r1' % 2 = 1` (odd divisor of an odd number yields odd quotient).
6) Lemma (uniqueness): If `2^p * x = 2^q * y` with `x%2=1` and `y%2=1`, then `x = y`.
   Apply it to the equality from (4) and `hB_eq`, using (5) and `hr2_odd`, to conclude `r2 = r1'`.
