5) Conclude the stated inequality by rewriting with (4) and applying (3).

3) Lemma (contradiction-with-hcard): combine (2) with hcard K to rule out N+1 distinct witnesses.
4) Lemma (finite-from-no-N+1-distinct): if a set has no N+1 distinct elements for some N, then it is finite.
5) Apply (4) to {k | P k} using (3).

lemma odd_part_noninc_step
  (m n : ℕ → ℕ)
  (h_recurrence : ∀ k : ℕ,
    (m (k + 1) : ℚ) / (n (k + 1) : ℚ) = ((2 : ℚ) * (m k : ℚ) + 1) / ((2 : ℚ) * (n k : ℚ) + 1))

  ∀ k u1 r1 u2 r2,
    Int.natAbs ((m k : ℤ) - (n k : ℤ)) = (2 : ℕ) ^ u1 * r1 →
    r1 % 2 = 1 → 0 < r1 →
    Int.natAbs ((m (k + 1) : ℤ) - (n (k + 1) : ℤ)) = (2 : ℕ) ^ u2 * r2 →
    r2 % 2 = 1 → 0 < r2 → r2 ≤ r1 := by
Failure mode: HARD
Recommendation: This is the key arithmetic step and needs explicit intermediate structure connecting successive differences via the gcd-normalization.
1) Lemma (successor_is_gcd_quotient): letting dₖ = gcd(2 m k + 1, 2 n k + 1), show m(k+1) = (2 m k + 1)/dₖ and n(k+1) = (2 n k + 1)/dₖ (derived from the ℚ recurrence plus coprimality of m(k+1),n(k+1)).

4) Lemma (odd_part_monotone_under_division_by_odd): if a ≠ 0 and d is odd with d ∣ a, then the odd part of a/d is ≤ the odd part of a. (Formulate using your decompositions `a = 2^u*r` with r odd.)
5) Apply (4) to a := (m k : ℤ) - (n k : ℤ) and d := dₖ, then transfer the resulting comparison to the particular r1,r2 coming from the given decompositions (uniqueness of odd part among “odd factors” gives the inequality r2 ≤ r1).
